# EquiShop

Vitrine estática em HTML, CSS e JavaScript, com menu mobile, animações ScrollReveal e carrossel Swiper. Sem checkout ou backend.

**Área do portfólio:** [Desenvolvimento de Software](https://github.com/alefkaue#desenvolvimento-de-software) · **Contexto:** Estudo de interface

## Conteúdo e tecnologias

**Linguagens identificadas:** CSS, HTML, JavaScript.

- [`animaçoes/main.js`](animaçoes/main.js)
- [`animaçoes/styles.css`](animaçoes/styles.css)

## Visualizar

Use um servidor estático na raiz para resolver os assets, por exemplo:

```console
python -m http.server 8000 --bind 127.0.0.1
```

Abra `http://127.0.0.1:8000/animaçoes/index.html`. Imagens e bibliotecas por CDN dependem de internet.

## Limites e aprendizagem

Registro de aprendizagem, sem backend ou operação comercial comprovada. Links de exemplo e formulários podem ser somente visuais. Não há suíte automatizada/CI demonstrada para estes arquivos; esta revisão alterou documentação, sem refazer a aplicação. Créditos de assets e bibliotecas permanecem nos arquivos de origem.
